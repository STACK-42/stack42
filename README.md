# stack42

A small lab. We build tools and ship them.

stack42 is our experimental playground. We're a band of undergrad freshers and one "wise" recent grad who are still figuring things out. This organization is where we test our apps and collaborate on projects.

## Projects

- **csdecoded** — Notes and reference for computer science topics  
  [csdecoded.stack42.tech](http://csdecoded.stack42.tech/)
- **schoolers** — Alumni directory and community network for FMSI and School of Mathematical Sciences & Informatics graduates  
  [schoolers.space](https://schoolers.space/)
- **aeset** — After Effects project scaffolding tool. CLI for setting up motion design projects with studio-standard folder structure  
  [aeset.stack42.tech](http://aeset.stack42.tech/)
- **peeko** — The to-do list that checks itself. A local-first macOS menu bar app that ticks off your daily habits (reading, focus, code, sleep, writing) when it sees the evidence  
  [peeko.stack42.tech](https://peeko.stack42.tech/)
- **relaunch** — The paged app grid, back on your Mac. A free, open-source launcher that restores your old Launchpad layout, folders and all  
  [relaunch.stack42.tech](https://relaunch.stack42.tech/)

## Development

This project uses **bun** as its package manager. [Install bun](https://bun.sh/).

```sh
git clone https://github.com/STACK-42/stack42.git
cd stack42
bun install
bun run dev
```

For more details, see [CLAUDE.md](CLAUDE.md).
